# Prose style

Write simplified technical english in inverted-pyramid order, summary first and detail after.
Every section opens with an overview thesis sentence. Every paragraph opens with a thesis
sentence. One idea per sentence. Under 20 words per sentence. Active voice, present tense, plain
words. No connecting punctuation. No metaphors, no idioms, no synonyms for a term the code
already names. Short paragraphs and sections unless the subject requires detail.

Structure each document and each major section as orientation, then breakdown. Orientation
introduces background, concepts, code organization, and requirements. Breakdown gives filenames,
functions, argument lists, algorithms, data structures, and services needed to map the discussion
to code.

Scope: edit only what a code change made false or incomplete. Do not create new markdown files,
add sections, or expand existing text unless asked. Use American English.
